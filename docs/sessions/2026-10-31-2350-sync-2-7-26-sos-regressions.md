# 2026-10-31: SOS regressions of the v2.7.26 sync (W4, class S)

- **Goal**: fix the three SOS-path regressions and the snapshot leftovers named in the post-landing review of treklink-firmware#22 (`dev` at `db34bca`), under D-087 (TrekLink behaviour wins; stock edits small and marked). Branch `fix/sync-2-7-26-sos-regressions`.
- **LED (v3)**: upstream #9512 renamed the T-Beam `LED_PIN` to `LED_POWER`, so `#ifdef LED_PIN` compiled out on v3 in `TrekLinkSOSGesture.cpp:118`, `TrekLinkSOSHelper.cpp:93`, `TrekLinkButtonModule.cpp:314` and `FallDetectionModule.cpp:310` (that module is excluded on v3 anyway). Fixed with an `LED_PIN LED_POWER` alias in `variants/esp32/treklink_v3_tbeam/variant.h`. v4 needs nothing: stock `tbeam-s3-core` defined no `LED_PIN` before or after the sync. Every hardware macro TrekLink code tests was compared per variant at `f062a35` and `db34bca`; `LED_PIN` on v3 is the only one lost.
- **Position precision**: Router now clamps originated position packets to the channel precision (stock default 13 bits). Each TrekLink `variant.h` sets `USERPREFS_CHANNEL_0_PRECISION 32`, read by stock `Channels.cpp:155`; no stock source edit, stock envs unchanged. Applies to a freshly written default channel only (first boot, factory reset). New native suite `test/test_treklink_position_precision`.
- **SOS position without coordinates (pre-existing, before the sync)**: `TrekLinkSOSHelper::sendPositionPacket` set `latitude_i`, `longitude_i` and `altitude` without their `has_` flags, which nanopb needs to encode an OPTIONAL field (`mesh.pb.h:1880-1882`), so the first SOS position packet carried no coordinates. SOS beacons use `PositionModule::sendOurPosition()` and do carry them; before the sync they were already clamped to 13 bits. Leader ruling: fix it here. The three flags are now set (`TrekLinkSOSHelper.cpp:109-112`); `test_treklink_position_precision` pins the encoding rule, since the helper itself only compiles with `TREKLINK_VARIANT` and the native env does not define it.
- **OK-to-MQTT**: ported `f63c621d6` as the strong definition of the stock weak `variantDefaultConfig()` in the TrekLink-only `src/mesh/TrekLinkVariantDefaults.cpp`, setting `config.lora.config_ok_to_mqtt = true`. No stock file edit. Applies at first boot and factory reset only.
- **Snapshot leftovers**: 42 stock files regained `100755` (31 under `bin/`); `.dockerignore` is again the upstream symlink to `.gitignore`. The review counted 71 (56 under `bin/`); this tree shows 46 executable files in upstream `54e0d8d` and 4 at `db34bca`.
- **Stock-edit list**: the repository keeps none; this branch adds no stock source edit.
